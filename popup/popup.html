📝 Logseq 同步设置说明：

  1. 开启"开发者模式" 设置>高级设置>开发者模式
  2. 开启"HTTP APIs server" 更多功能>HTTP APIs server
  3. 重启 Logseq 以使设置生效
  4. Logseq 右上角 API 功能设置 Token
  5. Start server
  6. 本界面填入配置的 Token 点击"连接 Logseq"

详细说明请参考：Logseq HTTP Server 文档

📦 增量导出：

  1. 终端运行 node scripts/local-inbox-server.mjs
  2. 打开星球主题页，点悬浮窗「导出增量」（自动滚动抓取）
  3. 有截止点 → 导出截止点之后；无截止点 → 导出近 N 小时（默认 48h）
  4. 终端运行 node scripts/build-daily-pipeline.mjs 生成 HTML

说明见 docs/DAILY-PIPELINE.md

内容区域右键点击"解释内容"来使用。
